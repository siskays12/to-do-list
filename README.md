
# TaskFlow - To-Do List

TaskFlow adalah aplikasi manajemen tugas sederhana berbasis HTML, CSS, dan JavaScript. Aplikasi ini dibuat sebagai proyek kelompok untuk mempraktikkan kolaborasi menggunakan Git dan GitHub.

## Tujuan Proyek

Membuat aplikasi yang membantu pengguna mencatat, mengelola, dan memantau penyelesaian tugas sehari-hari.

## Fitur Aplikasi

- Menambahkan tugas baru.
- Menentukan tenggat waktu tugas.
- Menandai tugas yang telah selesai.
- Menghapus tugas.
- Memfilter tugas berdasarkan status.
- Menampilkan jumlah total, tugas belum selesai, dan tugas selesai.
- Menyimpan data tugas menggunakan localStorage.
- Tampilan responsif untuk desktop dan perangkat seluler.

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Cara Menjalankan Aplikasi

1. Clone repository ke komputer:

   ```bash
   git clone https://github.com/siskays12/to-do-list.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd to-do-list
   ```

3. Buka folder proyek menggunakan Visual Studio Code.

4. Buka file `index.html` menggunakan browser atau ekstensi Live Server.

## Alur Kolaborasi Git dan GitHub

1. Developer mengerjakan fitur pada branch pengembangan.
2. Developer menyimpan perubahan menggunakan commit.
3. Developer melakukan push ke GitHub.
4. Developer membuat Pull Request.
5. Reviewer memeriksa kode dan memberikan komentar.
6. Developer memperbaiki kode jika diperlukan.
7. Perubahan yang disetujui digabungkan melalui proses merge.

## Penyimpanan Data

Aplikasi menggunakan localStorage pada browser untuk menyimpan daftar tugas. Data tersimpan pada browser yang digunakan dan tidak otomatis tersinkronisasi dengan perangkat lain.
